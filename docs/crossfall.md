# 도로 횡단구배 — 0.11

## 부호와 단면

좌·우는 시점에서 종점으로 진행하는 방향 기준입니다. 중심 계획고는 종단선형 표고 + 계획고 보정입니다. 하향 구배 q(%)가 양수면 중심에서 가장자리로 낮아지고 음수면 높아집니다. 왼쪽/오른쪽 값을 독립 지정하며 노선 전체에 일정하게 적용합니다. 기본값은 0/0입니다.

중심으로부터 수평거리 d, 전체 폭 W에 대해 도로 안쪽 높이는 `z = z_center − |d| × q_side / 100`입니다. 가장자리 높이는 `z_edge = z_center − (W/2) × q_side / 100`입니다. 20m 폭의 기능 확인 예로 좌 2%, 우 4%이면 중심보다 좌측 가장자리 0.2m, 우측 0.4m 낮습니다. 이 수치는 설계기준 권장값이 아닙니다.

도로 바깥에서는 중심 대신 해당 가장자리 높이를 기준으로 H:V 사면을 연결합니다. `e = max(0, |d| − W/2) / 사면비`이고 원지반이 계획면보다 낮으면 성토 `max(ground, z_edge − e)`, 높으면 절토 `min(ground, z_edge + e)`입니다. 내부 도로 면은 위의 선형 단면을 사용합니다.

원본 계산용 DEM은 수정하지 않습니다. 공간 검색의 최근접 중심선 선분에서 좌·우를 결정합니다. 로컬 동/남 좌표에서 진행 벡터와 점 방향의 외적이 양수이면 우측입니다. 곡선 사면은 기존의 조밀한 선형 폴리라인 근사와 동일하며 자기 교차·끝단 사면의 정확한 체적 합집합은 계산하지 않습니다.

## 화면·지형·수량

횡단과 지형 작업 스레드, 단면별 토공량은 같은 구배 함수를 공유합니다. 지형 검색·영향 타일 범위는 양쪽 가장자리의 가능한 높이 차이까지 보수적으로 확장합니다. 도로 리본은 좌측·중앙·우측 정점열로 구성하여 중앙이 높은 형상을 나타냅니다. 기존과 같이 리본만 가시성을 위해 0.5m 들어 표시하며 이 표시 오프셋은 지형·수량에 포함하지 않습니다.

도로의 중심 계획고와 PVI는 바뀌지 않습니다. 평면 PI를 이동하거나 방향을 바꾸면 좌·우는 새 진행 방향을 따릅니다. 횡단 그래프는 왼쪽 화면이 진행 방향 좌측, 오른쪽이 우측입니다. 그래프는 원지반과 사면까지 함께 표시하므로 작은 구배 차이는 표시 축척에 따라 작게 보일 수 있습니다.

절토·성토는 중심과 도로 양 가장자리를 포함한 횡단 표본에서 적분합니다. 평탄 지반에 폭20m, 중심2m, 좌2%·우4%, H:V=1.5의 단면은 도로부37m² + 사면부4.35m² = 성토41.35m²입니다. 중심−2m이면 절토50.95m²입니다. 단면 두 개가 100m 간격으로 같으면 각각 4135m³ / 5095m³로 평균단면법 결과를 검증했습니다.

토공량 CSV에 `left_down_pct`, `right_down_pct`를 마지막 두 열로 추가했습니다(19열). 기존 17열의 순서는 유지합니다. 수량의 다른 제한은 [토공량 문서](earthwork.md)와 같습니다.

## 저장·이력·지원 범위

프로젝트 v5는 `crossfall.left/right`에 퍼센트 숫자를 저장합니다. v1~v4에서는 이 값을 사용하지 않고 0/0으로 초기화하여 기존 단면을 보존합니다. v5의 누락·비숫자·비유한·범위 밖 입력은 현재 프로젝트를 바꾸지 않고 거절합니다. 0.10 이하 앱은 v5를 열 수 없습니다. 바이너리 컨테이너 헤더 KROAD2는 유지합니다.

횡단구배는 설계 이력과 비동기 작업 스냅샷에 포함합니다. 양쪽 입력 후 적용 한 번이 undo/redo 한 단계입니다. 변경·undo/redo는 기존 revision 경로로 지형을 갱신하고 이전 수량·검토 결과를 무효화합니다. 입력 제한 ±12%는 현재 소프트웨어 범위이며 설계기준 한계값이 아닙니다.

이번 단계는 일정 단면입니다. 측점별 편경사·전이 길이·회전축, 곡선에 따른 자동 구배, 길어깨·중앙분리대·포장층, 차로별 확폭을 구현하지 않았습니다. 설계 검토표도 횡단구배의 기준 적합성을 판정하지 않습니다.
