# 횡단 DXF 격자와 실제 표고 눈금 (0.39)

횡단 DXF 창의 격자·표고 눈금으로 켭니다. 기본은 꺼짐, 초기 간격은 10m이며 0.5~1,000m 범위입니다. 입력 설정은 창에 유지하고 프로젝트에 저장하지 않습니다.

## 격자 좌표

가로 오프셋은 중심선 0을 기준으로 지정 간격의 배수에 세로선을 그립니다. 0과 조사 반폭 양 끝은 중복 격자에서 제외합니다. 가로선은 각 횡단의 DATUM에서 지정 간격만큼 위로 그리며 기본 축선과 중복되는 0은 제외합니다. 가로/세로 간격 모두 m이므로 H:V=1:1입니다. 가로선 높이는 한 도면의 공통 표시 높이 안에서 설정합니다. 조사 반폭과 기존 전체 표고 범위, DATUM/셀 배치는 바꾸지 않습니다.

`KROAD_SEC_GRID`(색 8)에 열린 3D POLYLINE/모든 Z=0으로 격자를 기록합니다. `KROAD_SEC_GRID_TEXT`(색 7)에 DATUM 및 격자 높이에 대응하는 실제 표고를 소수 둘째 자리로 표시합니다. 기존 도로/지표/축/문자 레이어는 그대로입니다. 큰 간격으로 격자선이 하나도 생기지 않아도 DATUM 표고는 표시합니다.

## 문자와 제한

표고 눈금은 각 셀 왼쪽 여백에 놓습니다. 실제 표고 = DATUM + (도면 Y − 셀 원점 Y)입니다. 음수 표고도 그대로 표시합니다. 촘촘한 격자에서는 `ceil(문자 높이×3/격자 간격)`칸마다 표고 문자를 표시하여 최소 세 문자 높이의 간격을 확보합니다. 기본 격자선 자체는 생략하지 않습니다.

격자 후보 수(기본 축과 겹치는 후보 포함)를 한 횡단당 500개, 전체 20,000개로 제한합니다. 초과하면 간격을 늘리거나 출력 구간/조사 반폭을 줄이도록 안내합니다. UI에 표시하는 격자 선 수는 중복 기본 축을 제외한 실제 출력 개수입니다. 기존 500횡단/100,000표본 제한도 유지합니다.

## 상태와 검증

격자를 껐을 때는 기존 도면과 같은 문자열을 생성합니다. 켰을 때도 기존 지표·설계선·축 좌표, 샘플 수와 횡단 요약은 유지합니다. 구간·추가 STA·주요 경계 옵션과 같이 사용할 수 있습니다. 격자 설정 변경 및 비동기 완료/저장 직전 입력 서명을 통해 오래된 결과를 거부합니다. 설계/undo 이력·프로젝트 v7·DLL v018은 변경하지 않습니다.

`verify_section_grid.gd`: 선택적 격자·기존 형상/표본 보존·끄기 호환·음수 DATUM·촘촘/큰 간격·유한성/입력 범위·한 횡단/전체 격자 예산·구간/추가 STA/경계 조합.

`--section-grid-smoke`: 기본 꺼짐·간격 편집 상태·실제 저장 신호·모델/이력 불변·설정 무효화·오래된 계산/저장 거부.

`tests/verify_section_grid_export.py`: 독립 ezdxf 오류/자동 수정 0건, 정확한 1:1 격자 좌표와 간격·양수/음수 표고 눈금·촘촘한 문자 간격·기존 지표/설계/축 정점의 완전 보존·UI 파일. 기존 주요 경계/추가 STA/횡단 구간/종단/평면 DXF 회귀 검사도 통과했습니다. UI와 음수 표고의 CAD 도면을 렌더링하여 확인했습니다.
