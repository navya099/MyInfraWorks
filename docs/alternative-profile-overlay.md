# 보관 대안 종단 중첩 — 0.25

대안 창에서 보관본을 선택하고 선택 대안 평면·종단 중첩을 켭니다. 평면과 종단이 같은 선택을 사용합니다. 종단의 보라색은 보관본 계획고, 주황색은 현재 계획고, 녹색은 현재 노선을 따른 원지반입니다. 어느 뷰의 중첩 해제 버튼이나 대안 창의 체크 해제로 둘 다 지웁니다.

## 표고와 측점 기준

보관본으로 구성한 네이티브 선형의 독립 PVI 측점·표고·종단곡선 길이와 계획고 보정을 사용합니다. 접선 구배와 포물선 구간 계수를 캐시하여 보관 계획고를 평가합니다. PVI 제어점들을 단순 직선으로 연결하지 않습니다. 캐시 계산은 볼록/오목 곡선·경계·끝점과 무곡선 교점에서 네이티브 표고와 대조합니다. 그릴 때는 현재 표시 범위의 표본과 PVI/BVC/EVC를 포함해 선분으로 표시하므로 화면용 근사 선이며 수량 산식이나 설계 정밀도를 바꾸지 않습니다.

두 노선은 노선 시작 0 기준의 같은 절대 수평 호장 STA(m)와 표고 축에 표시합니다. 노선 길이에 비례해 맞추지 않고 각 노선의 0~길이 안에서만 그립니다. 길이가 다르면 짧은 노선의 선은 먼저 끝나며 범위 밖을 외삽하지 않습니다. 전체 맞춤의 가로 범위는 두 길이 중 큰 값까지이고 세로 범위에는 두 노선의 표고와 현재 지형 범위를 포함합니다. 보관 PVI 제어고 범위를 사용하므로 실제 포물선보다 여유가 있을 수 있습니다.

서로 다른 평면 경로의 같은 STA가 같은 지리적 지점이라는 의미는 아닙니다. 같은 지점의 수직 차이나 교차 판정·토공량을 산출하지 않습니다. 보관 노선의 원지반을 별도로 조회/표시하지 않으며 녹색 선은 현재 노선만의 원지반입니다. 3D·횡단 중첩은 포함하지 않습니다.

## 화면 조작과 캐시

종단의 기존 휠 확대, Shift 가로 확대, Ctrl 세로 확대, 가운데 드래그와 전체 맞춤을 사용합니다. 수동 화면 범위는 대안을 바꾸어도 유지하므로 보관 선이 보이지 않으면 전체 맞춤을 누릅니다. 현재 노선 초기화 후에도 보관 종단은 남아 확대/이동할 수 있습니다. 현재 노선이 없을 때 기존 측점 맞춤은 이동할 현재 측점이 없어 동작하지 않습니다.

보관 선에는 PVI 핸들을 만들지 않습니다. PVI 선택/드래그/추가는 현재 노선만 바꾸고 보관본은 유지합니다. 표시를 켜고 끄거나 화면을 이동해도 설계·보관 목록·undo/revision·수량 결과·DEM·지형 메시를 변경하지 않습니다.

선택한 보관 설계가 바뀔 때 한 번 네이티브 선형과 평면 표시점을 만들고 종단의 접선/포물선 계수를 보관합니다. 화면 표본은 계수를 사용하며 반복적인 보관 평면 위치 계산과 DEM 조회가 없습니다. 이름 변경은 두 범례만 갱신하고 현재 노선 수정은 참조를 다시 구성하지 않습니다. 선택 삭제·새 DEM/프로젝트/데모와 중첩 해제 시 두 뷰의 참조를 함께 비웁니다.

프로젝트 v7·DLL v018을 유지하고 중첩 표시 상태·참조 캐시·화면 범위를 프로젝트에 저장하지 않습니다. 기존 프로젝트를 열 때 중첩은 꺼진 상태입니다.
