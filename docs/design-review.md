# 사용자 기준 설계 검토 — 0.10

## 범위와 설정

사용자가 입력한 최소 R, 최소 Ls, 최대 절대 종단구배, 볼록·오목 최소 K와 현재 선형을 비교합니다. 초기값 R=300m, Ls=50m, 구배=5%, 볼록/오목 K=20m/%는 기능 확인용 예시입니다. 설계속도나 도로 등급으로부터 산정한 법정 기준 또는 권장값이 아닙니다. 적용할 값을 직접 설정하세요. 0이면 해당 비교를 생략합니다. 무곡선 경고는 기준 0과 별개입니다.

이 검토는 DEM 표본이나 중심선 폴리라인 대신 독립 PVI·평면 PI의 매개변수와 네이티브 선형 요소를 사용합니다. 별도 메시 작업이나 지형 변경은 없습니다. 검토 설정과 결과는 현재 실행 동안만 유지하며 프로젝트 v4에는 저장하지 않습니다.

| 코드 | 표시 | 의미 |
|---|---|---|
| R_MIN | 최소 반경 | R이 양수인 내부 PI의 R < 최소값 |
| LS_MIN | 최소 완화길이 | 곡선 PI의 각 진입·진출 Ls < 최소값. Ls=0도 비교 |
| GRADE_MAX | 최대 종단구배 | 실제 종단 절대구배가 최대값을 넘는 접선/포물선 구간 |
| K_CREST_MIN | 볼록 K | 뒤 구배가 작아지는 포물선의 K < 볼록 최소값 |
| K_SAG_MIN | 오목 K | 뒤 구배가 커지는 포물선의 K < 오목 최소값 |
| H_KINK | 평면곡선 미설정 | 방향 변화가 있는 R=0 PI. 경고이며 사용자 수치 기준 비교와 구분 |
| V_KINK | 종단곡선 미설정 | 구배 변화가 있는 Lv=0 PVI. K를 0으로 표시하지 않고 경고 |

## 산식과 측점

PVI 사이의 접선구배(%)는 `g = 100 × 높이차 / 측점차`입니다. 포물선 종단곡선에서 구배는 진입 g1에서 진출 g2까지 선형 변화합니다. 최대 절대 구배는 이 양 끝값과 접선구배에서 구합니다. 구배가 ±한계를 지나는 측점은 선형식을 풀어 얻으며, 검사 간격에 따라 누락되는 방식이 아닙니다. 위반 범위는 한계와 같은 경계점까지 표시하고 행 선택은 그 범위의 중간으로 이동합니다. 인접 접선/곡선의 행을 합치지 않으므로 한 PVI 주변에서 여러 구배 행이 나올 수 있습니다.

`A = |g2 − g1|`은 퍼센트포인트 구배차이고 `K = Lv / A`입니다. Lv가 m이므로 K 단위는 m/%입니다. 예: +10%에서 −10%, Lv=200m이면 A=20, K=10m/%입니다. K 정의는 [FHWA의 종단곡선 설명](https://www.fhwa.dot.gov/publications/research/safety/17098/009.cfm)을 참고했습니다. 여기서 사용하는 최소 K 예시값은 해당 자료에서 가져온 기준값이 아닙니다.

구배차가 0이면 K를 계산하지 않습니다. 부동소수점 여유로 구배차 1e−8 퍼센트포인트 이하는 무변화로 취급합니다. 평면 편각 1e−7 rad 이하는 직선으로 취급합니다. 사용자 수치 한계와 같은 값은 위반이 아닙니다(비교 허용오차 1e−8).

반경·완화길이 지적 범위는 해당 PI의 진입 완화곡선부터 진출 끝까지입니다. 무곡선 교점은 한 측점입니다. 구배 지적은 실제 초과 구간이며, 표의 실제값은 그 구간의 최대 절대 구배입니다. K는 종단곡선 전체 범위를 표시합니다. 행 선택 시 PI/PVI 번호와 측점은 현재 설계 revision에 맞는 결과에서만 사용합니다.

## CSV와 결과 유효성

UTF-8 BOM의 22열 CSV는 summary 행과 finding 행으로 구성됩니다. 모든 행에 기준값·노선 길이·실제 최대 절대 구배·검사 수·위반/경고 수를 포함합니다. finding은 코드·위치 종류/번호(1부터)·시작/끝/이동 측점·실제값·기준값·단위·사유를 추가합니다. 수치 기준이 없는 무곡선 경고의 limit_value는 빈 셀입니다. 지적이 없어도 summary 한 행은 저장됩니다.

설계 변경·DEM 교체·프로젝트 불러오기·기준 변경은 결과를 지우고 내보내기를 막습니다. undo/redo 후에도 다시 검토합니다. 유효하지 않아 거절된 편집은 revision을 바꾸지 않으므로 결과를 유지합니다. CSV 저장 시 revision을 다시 확인합니다.

검토 항목은 위 표에 한정됩니다. 설계속도·정지시거·편경사·배수·교차로·자기 교차·DEM 적합성·국내 도로 설계기준의 전체 요구조건은 검사하지 않습니다. 지적 없음은 입력한 비교에서 지적이 없다는 의미입니다.
