# 횡단 DXF 일괄 출력 — 0.29

상단 DXF 창의 횡단 DXF...를 열고 조건을 지정해 산출한 뒤 DXF 저장을 누릅니다. 현재 노선 전체에서 0과 정규 간격 측점, 정확한 종점을 출력합니다. 종점이 정규 측점과 거의 일치하면 약 10⁻⁷m 이내 중복을 제거하고 정확한 종점을 우선합니다. PI/PVI 등 별도 추가 측점을 자동으로 횡단 목록에 넣지는 않습니다.

기본 조건은 측점 간격 1,000m, 조사 반폭 100m, 횡단 표본 간격 2m, 3열 배치입니다. 범위는 각각 1~10,000m / 5~10,000m / 0.1~50m / 정수 1~8열입니다. 최대 500횡단, 횡단당 20,000표본, 전체 100,000표본을 넘으면 조건 변경을 안내합니다. 표본은 조사 양 끝·현재 중심·범위 안의 양 도로 가장자리와 정규 간격을 포함합니다.

## 좌표·축척·도형

1 도면 단위는 1m이고 가로·세로에 같은 배율을 적용합니다. 각 횡단을 열/행으로 배치하고 `X = 배치 중심 X + 횡단 오프셋`, `Y = 배치 기준 Y + 표고 − DATUM`, `Z = 0`으로 출력합니다. 음수 오프셋은 현재 노선 좌측이고 위쪽은 높은 표고입니다. CAD에서 가져오기 단위를 m로 지정합니다. R12에는 이 출력의 자동 삽입 단위를 설정하지 않습니다.

DATUM은 각 횡단의 유효 원지반/설계 표고 최솟값 아래 10m 단위 기준표고입니다. 유효 표본이 없으면 현재 중심 계획고를 기준으로 정합니다. 모든 횡단은 같은 세로 배율을 사용하되 DATUM이 다를 수 있으므로 서로 다른 도면의 Y좌표를 절대 표고로 바로 비교하지 않습니다. 원래 표고는 `Y−배치 기준 Y+DATUM`으로 복원합니다. 배치 간격은 전체 횡단 중 가장 큰 표고 범위를 고려해 겹치지 않도록 정합니다.

폴리라인은 R12 열린 3D POLYLINE/32 플래그 VERTEX이며 Z를 모두 0으로 기록합니다. 선이 없는 단독 표본은 POINT입니다. 축도 열린 폴리라인으로 그립니다. TEXT 표기는 ASCII 호환 영문이며 각 횡단에 STA·H:V 1:1·DATUM·현재 중심 계획고·결측 개수·반폭/횡단 간격을 표시합니다. 오프셋 양 끝과 0도 표기합니다. POINT 가시성은 CAD의 점 표시 설정으로 조정할 수 있습니다.

| 레이어 | 내용 | 색상 |
|---|---|---|
| KROAD_SEC_GROUND | 원지반 | 초록 |
| KROAD_SEC_DESIGN | 현재 설계면 | 노랑 |
| KROAD_SEC_AXIS | 오프셋/기준표고 축 | 회색 |
| KROAD_SEC_TEXT | STA·기준표고·조건 문자 | 흰색 |

지도/EPSG 좌표나 3D 지형 위치로 배치한 횡단면이 아니라 모델 공간에 나열한 횡단 도면입니다. Civil 3D Section 객체·표제란·출력 용지 레이아웃을 만들지 않습니다. 전체 현재 노선을 내보내며 보관 대안은 적용 후 현재 설계로 출력할 수 있습니다.

## 평가·결측·유효성

원본 DEM과 현재 노선의 준비된 네이티브 공간 검색을 사용합니다. 횡단 기준 point/normal과 설계면 계산은 기존 횡단 뷰/표와 같습니다. 폭·보정고·좌우 횡단구배·절토/성토 사면을 반영합니다. 표본 사이를 직선으로 연결하므로 곡선·사면 접속의 화면용 근사이고 표본보다 세밀한 지형이나 정확한 사면 접속점은 추출하지 않습니다. 조사 반폭이 도로/사면 전체를 포함한다는 보장은 없으며 폐합 판정이나 단면적/체적을 산정하지 않습니다.

원지반과 설계면의 유효성을 각각 확인합니다. 결측/범위 밖에서 선을 끊고 다음 유효 표본부터 새 도형을 만듭니다. 0 표고를 결측으로 사용하지 않습니다. 전체가 결측인 횡단은 축/문자와 결측 개수를 남기고 설계/원지반 선을 만들지 않습니다. UI의 도형 조각 수는 폴리라인과 단독 POINT를 모두 셉니다.

설계/DEM/측점 간격/반폭/횡단 간격/배치 열 수 변경은 결과를 비우며 산출 완료 시 revision과 조건 세대를 다시 확인합니다. 현재 STA 이동은 전체 노선 출력 조건이 아니므로 결과를 유지합니다. 산출과 저장은 설계·undo·원본 DEM·메시를 바꾸지 않고 임시 파일 완성 후 교체합니다. 프로젝트 v7·DLL v018을 유지하며 출력 조건/결과는 프로젝트에 저장하지 않습니다.

## 검증과 형식 참고

Godot 검사가 합성 지형의 일반/결측/전체 결측/단독 유효 점/음수 표고 DXF를 user://에 만들고 SECTION DXF FIXTURES 경로를 출력합니다. 이어 UI 검사로 실제 저장 신호 예제를 만든 뒤 그 경로를 tests/verify_section_dxf_export.py에 전달합니다. 독립 판독기 ezdxf 1.3.0으로 읽고 오류·자동 수정 0건, 실제 좌표/축척/층/표고·양쪽 2%/4% 구배·종점·결측 분리와 POINT 보존을 검사합니다. 별도 DXF 렌더링으로 배치와 문자도 확인했습니다. AutoCAD에서 직접 실행한 검증은 아닙니다.

추가 엔티티의 코드는 Autodesk의 [TEXT 명세](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-DXF/files/GUID-62E5383D-8A14-47B4-BFC4-35824CAE8363.htm)와 [POINT 명세](https://help.autodesk.com/cloudhelp/2020/ENU/AutoCAD-DXF/files/GUID-9C6AD32D-769D-4213-85A4-CA9CCB5C5317.htm)를 참고했습니다. POLYLINE 형식은 [기존 DXF 출력 설명](dxf-export.md)의 R12 명세를 따릅니다. Python/ezdxf는 검사 도구에만 필요하며 Godot 내보내기는 이에 의존하지 않습니다.
