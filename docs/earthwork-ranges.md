# 측점 범위별 토공량 — 0.22

토공량 창에서 현재 설계의 수량 계산 후 측점 범위 집계를 엽니다. 시작·끝 STA(m)를 입력하고 범위 집계 또는 Enter를 누릅니다. 전체 구간 버튼은 원본 조사 양 끝의 실제 값을 사용합니다. 측점은 노선 시작 0을 기준으로 한 수평 선형 호장입니다. 시점 오프셋/측점 방정식은 적용하지 않습니다.

기존 [평균단면법 결과](earthwork.md)의 단면적과 유효 구간을 재사용합니다. DEM을 다시 조사하지 않으며 범위를 좁히거나 소수점 자리를 늘려도 원본 조사 정밀도가 높아지지 않습니다. 도로 폭·보정고·횡단구배·사면과 조사 반폭/간격은 해당 원본 결과와 같습니다. 프로젝트 v7·DLL v018을 유지하고 범위 입력과 집계 결과는 프로젝트에 저장하지 않습니다.

## 범위 경계 계산

원본 조사 구간 s0~s1의 절토/성토 면적 A0, A1을 각각 별도로 선형 보간합니다. 요청 범위와 겹친 부분을 a~b라고 하면 다음과 같습니다.

```text
A(s) = A0 + (A1 - A0) × (s - s0) / (s1 - s0)
V(a,b) = [A(a) + A(b)] × (b - a) / 2
```

예를 들어 0~100m에서 절토 면적이 10→30m²라면 전체 체적은 2,000m³이고 20~60m의 면적은 14→22m², 부분 체적은 720m³입니다. 전체 체적의 40%인 800m³를 사용하는 방식과 다릅니다. 같은 조사 구간을 여러 범위로 나누어 합하면 원래 평균단면법 체적과 일치합니다(부동소수점 오차 제외). 새 단면을 실제 지형에서 추출한 결과와 같다고 가정하지 않습니다.

제외된 원본 구간은 일부만 걸쳐도 겹친 부분 전체를 제외합니다. 한쪽 단면만 유효하다고 다른 쪽을 복원하지 않습니다. 요청 경계가 정확히 조사 측점에 있으면 접하기만 한 바깥 구간은 포함하지 않습니다. 0 ≤ 시작 < 끝이고 원본 조사 범위 안이어야 하며 잘못된 숫자·비유한 값·역순·범위 밖 입력은 자동 보정하지 않고 거절합니다.

## 표시와 유효성

- complete: 요청 범위 전부 유효. 절토·성토와 차이를 표시합니다.
- partial: 유효한 겹침 구간만의 부분합. 분모는 요청 범위 전체 길이입니다.
- missing: 유효 구간 없음. 세 수량은 NA/CSV 빈 셀이고 유효 비율은 0입니다. 실제 유효한 수량 0과 구분합니다.

유효 길이는 포함된 겹침 길이 합입니다. 제외 건수는 요청 범위와 양의 길이로 겹친 제외 원본 구간 수입니다. 표의 제외 사유는 양 끝 단면 상태(ok/nodata/unclosed)를 보존합니다. nodata는 DEM 결측/경계, unclosed는 조사 끝 사면 미접속입니다. 부분합을 전체 노선 수량으로 해석하지 않습니다. 절토−성토 차이에 토량변화율·지질·재료 적합성·운반·배분·비용은 반영하지 않습니다.

표는 200행씩 보여 주며 CSV는 현재 페이지와 관계없이 지정 범위 전체를 저장합니다. 행 선택은 표시 구간 중간 측점으로 이동하고 설계/undo/revision/원본 토공량을 변경하지 않습니다. 입력 범위 변경은 집계 결과만 지우고 원본 조사 결과를 유지합니다. 설계·DEM·원본 조사 조건 변경/재계산은 원본과 파생 결과를 함께 무효화하며 CSV 저장 시에도 revision과 입력 일치를 확인합니다.

## CSV 21열

```text
method,boundary_method,station_step_m,half_width_m,lateral_step_m,range_start_m,range_end_m,range_status,range_coverage_ratio,interval_start_m,interval_end_m,source_start_m,source_end_m,interval_status,cut_start_area_m2,cut_end_area_m2,fill_start_area_m2,fill_end_area_m2,cut_volume_m3,fill_volume_m3,detail
```

UTF-8 BOM, method=average_end_area, boundary_method=linear_section_area입니다. 길이 m, 면적 m², 체적 m³이며 coverage_ratio는 0~1입니다. range_*는 요청 범위 전체의 정보로 모든 행에 반복됩니다. interval_*는 요청 범위로 잘린 경계이고 source_*는 원본 조사 구간 경계입니다. 체적은 각 행 구간의 값이며 누계가 아닙니다. 제외 행의 면적과 두 체적은 비워 0과 구분합니다. 유효 행들을 합하면 범위의 절토·성토 부분합입니다. 임시 파일을 완성한 뒤 교체하며 유효하지 않은 결과는 내보내지 않습니다.
