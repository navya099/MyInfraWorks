# 절토·성토 사면비 분리 — 0.16

H:V는 수평 길이/수직 높이 비입니다. 값이 클수록 완만하고 작을수록 급합니다. 성토와 절토에 각각 노선 전체 일정값을 지정합니다. 기본은 두 값 모두 1.5입니다. 이 기본값이나 기능 검사용 수치는 토질별 권장 설계값이 아닙니다.

## 계산

도로 안은 중심 계획고와 좌·우 횡단구배로 정한 면을 유지합니다. 가장자리 밖의 수평 거리 e에 대해 성토 계획 높이는 `z_edge − e / fill_ratio`, 절토는 `z_edge + e / cut_ratio`입니다. 원지반과 계획면의 높이 관계에 따라 성토 또는 절토 쪽을 선택하고 지반과 만난 뒤에는 원지반을 유지합니다. [횡단구배](crossfall.md)의 가장자리 높이를 사용합니다.

단면적 적분에서 성토 높이는 `max(0, z_edge − ground − e/fill_ratio)`, 절토 높이는 `max(0, ground − z_edge − e/cut_ratio)`입니다. 중심과 도로 가장자리, 선형 보간 영점에서 나누는 기존 적분과 평균단면법을 유지합니다. 조사 끝에 절성토가 남거나 NoData이면 기존처럼 해당 단면/인접 구간을 제외합니다.

네이티브 직접 표고 질의, 준비된 중심선 공간 검색, 비동기 지형 타일, 수량 계산이 같은 두 사면비를 사용합니다. 영향 타일·검색 범위는 두 값 중 큰 사면비로 보수적으로 정해 절토 영향 범위가 누락되지 않도록 합니다. 입력 변경 전후 영향 타일을 합쳐 갱신합니다.

## 검사 예

평탄 지반, 폭20m, 중심이 지반보다 2m 높고 성토 H:V=2이면 단면적 `20×2 + 2×2² = 48m²`입니다. 중심이 2m 낮고 절토 H:V=0.5이면 `20×2 + 0.5×2² = 42m²`입니다. 동일 두 단면이 100m 간격이면 각각 4800m³, 4200m³입니다.

좌2%·우4% 구배를 더하면 같은 성토 단면은 42.8m², 절토 단면은 45.65m²가 됩니다. 20% 횡단 경사의 원지반에서 중심고0·폭20m, 성토2·절토0.5인 혼합 단면의 성토면적 50/3m²와 절토면적 100/9m²도 별도 해석값으로 확인했습니다.

## UI·저장·호환

상단 성토 H:V/절토 H:V를 입력하고 적용합니다. 범위는 각 0.1~10이며 소프트웨어 입력 제한입니다. 적용은 undo/redo 한 단계이고 수량·검토 결과를 무효화합니다. 횡단의 화면 축척 H:V=1:1과 사면비 H:V는 서로 다른 개념입니다. 전자는 가로/세로 표시 비율, 후자는 사면 자체의 기울기입니다.

프로젝트 v6의 `slope`는 성토비이고 `cut_slope`는 절토비입니다. v1~v5는 기존 slope를 두 값에 복사해 원래 형상을 유지합니다. v6의 절토비 누락·비숫자·비유한·범위 밖 값은 현재 프로젝트를 바꾸지 않고 거절합니다. 바이너리 KROAD2 헤더는 유지하며 0.15 이하 앱은 v6를 열 수 없습니다. 새 네이티브 DLL 이름은 kroad_core_v016입니다.

CSV는 기존 19열 뒤에 fill_slope_hv/cut_slope_hv를 추가한 21열입니다. 두 값은 조사/측점 설정과 함께 모든 행에 기록합니다. 수량 창에도 적용한 사면비를 표시합니다. 별도 절토비를 설정하지 않는 기존 네이티브 API 호출은 공유 사면비 동작을 유지합니다.

소단·다단사면·토질별 자동 판단·옹벽·교차 사면의 정확한 체적 합집합은 구현하지 않습니다. 다른 수량 제한은 [토공량](earthwork.md) 문서와 같습니다.
