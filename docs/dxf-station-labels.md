# 평면 DXF 측점 주석 (0.31)

DXF 창의 `STA 주석 추가`로 선택합니다. 기본은 꺼짐입니다. 주석 간격과 문자 높이를 정한 다음 산출하고 저장합니다. 이 설정은 프로젝트에 저장하지 않습니다.

## 형식과 크기

기존 R12 ASCII 3D POLYLINE 도로 레이어에 선택적으로 다음을 추가합니다.

| 레이어 | 요소 | 색상 |
|---|---|---|
| KROAD_STA_TICK | 열린 3D POLYLINE, 두 정점 | 6 |
| KROAD_STA_TEXT | TEXT, STA 미터 소수 셋째 자리 | 7 |

주석 간격은 10~10,000m이며 시점 0, 정규 간격, 정확한 종점을 포함합니다. 종점과 1mm 미만으로 가까운 정규 표식은 종점으로 대체합니다. 최대 2,000개를 초과하면 간격을 늘리도록 안내합니다. 기존 도로 정점 제한은 독립적으로 적용합니다.

표식 총 길이는 max(10m, 도로 전체 폭×1.5)입니다. 문자 높이 0은 clamp(폭/6, 1m, 20m)의 자동 크기이고, 수동 지정 범위는 0.1~100m입니다. 문자는 진행 방향 오른쪽으로 표식 반길이+문자 높이만큼 떨어진 지점에 배치합니다. 글자 충돌을 자동으로 회피하지는 않습니다.

TEXT의 삽입점은 그룹 10/20/30, 높이는 40, 내용은 1, 회전각은 50으로 기록합니다. [Autodesk TEXT DXF 명세](https://help.autodesk.com/cloudhelp/2023/ENU/AutoCAD-DXF/files/GUID-62E5383D-8A14-47B4-BFC4-35824CAE8363.htm)를 참조하세요.

## 좌표와 표고

기존 평면 DXF와 동일하게 X=동쪽, Y=북쪽, Z=설계 표고, 단위는 m입니다. 로컬/투영 좌표 선택을 따릅니다. 내부 남쪽 축의 부호를 바꾸며 투영 모드는 원점 좌표를 더합니다. 표식은 해당 측점의 실제 평면 접선에 수직입니다. 문자 회전은 CAD 북쪽 위 평면 기준 −90~90도로 정규화합니다.

표식 두 끝과 문자의 Z는 실제 종단곡선상의 중심 계획고+계획고 보정입니다. 화면 표시용 높이 띄우기를 제외합니다. 표식은 도로 가장자리의 횡단구배 표고나 지표면을 따르는 횡단 측량선이 아닙니다. 문자는 수평 평면에 놓입니다. 도면 범위는 표식과 회전된 문자의 보수적인 예상 범위까지 포함합니다.

주석은 기존 중심선·좌우 가장자리 형상을 바꾸지 않습니다. 입력·좌표 모드·설계·DEM 변경 시 산출물과 저장을 무효화하며 비동기 작업의 오래된 결과를 폐기합니다. 현재 STA 선택은 독립적입니다. 설계 모델·이력·프로젝트 v7·네이티브 DLL v018은 변경하지 않습니다.

## 검증

`verify_dxf_labels.gd`가 로컬/투영, 동서남북, 원곡선, 포물선, 수동 문자 높이, 종점 근접, 주석 끄기 DXF를 만듭니다. `--dxf-labels-smoke`는 실제 저장 신호, 기본 꺼짐, 간격/높이 변경 무효화, 계산 중 변경, 설계와 이력 보존을 검사합니다. 두 명령은 같은 사용자 데이터 경로에서 실행합니다.

`tests/verify_dxf_labels_export.py`에 출력된 fixture 폴더를 전달하면 ezdxf로 오류/자동 수정 0건, 정확한 좌표·Z·문자 회전·접선 수직·범위·종점 병합·기존 도로 정점 보존을 독립 검사합니다. UI와 원곡선 도면도 렌더링하여 확인했습니다. 기존 평면·종단·횡단 DXF UI 검사도 통과했습니다.

합성 3601×3601 DEM, 길이 약 98.235km에서 도로 41,265정점+1km 간격 주석 100개 생성은 약 645ms였습니다. 작업 스레드 생성 시간이며 화면 표시/파일 저장 시간은 제외한 단일 환경 측정입니다.
