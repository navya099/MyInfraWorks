# 측점표 페이지와 STA 찾기 (0.35)

측점표는 전체 산출 결과를 보관하되 화면에는 200행씩 표시합니다. 이전/다음 페이지와 현재 표시 행 범위/전체 행 수를 보여 줍니다. 첫 페이지에서 이전, 마지막 페이지에서 다음 버튼을 비활성화합니다. 페이지 전환 중 표를 다시 그릴 때 현재 STA를 이동시키지 않습니다.

## 탐색

표의 행을 선택하면 `페이지×200+화면 행 번호`에 해당하는 원래 STA로 이동합니다. 열 제목은 측점 이동 대상이 아닙니다.

찾을 STA(m)에 숫자를 입력하고 STA 찾기 또는 Enter를 누릅니다. 산출 구간 안의 유한한 값만 받으며, 이진 탐색으로 가장 가까운 기존 산출 행을 찾아 페이지와 행을 표시하고 해당 STA로 이동합니다. 같은 거리라면 작은 STA를 선택합니다. 예를 들어 1m 간격에서 399.5m를 찾으면 399m, 400m는 정확히 400m로 이동합니다. 새 측점이나 보간 행을 추가하지 않습니다. 잘못된 입력·범위 밖 입력은 안내만 하고 기존 페이지/현재 STA를 유지합니다.

## 계산과 저장

[구간 산출](station-table-range.md)과 측점 병합·좌표·표고 계산은 유지합니다. 전체 20,000행 한도도 그대로입니다. 작업 완료 시 전체 문자열을 만든 뒤 자르는 대신 필요한 200행만 화면 문자열로 만듭니다. CSV는 페이지와 관계없이 전체 결과를 저장하며 기존 UTF-8 BOM/21열 형식입니다.

입력·설계 변경 시 산출 결과와 페이지를 초기화합니다. 탐색과 저장 전에 revision/입력 서명을 확인하여 오래된 결과를 거부합니다. 재산출 성공 시 첫 페이지로 돌아갑니다. 설계와 undo 이력·프로젝트 v7·DLL v018을 변경하지 않습니다. 다른 DXF/비교 창의 표시 방식은 유지합니다.

## 검증

`--station-paging-smoke`에서 1,201행을 실제 산출하여 200행 페이지·마지막 1행 페이지·페이지 오프셋 행 선택·페이지 전환 중 현재 STA 보존·정확/중간 동률/종점 검색·범위 밖/잘못된 숫자·페이지 경계·입력 변경 초기화·모델/이력 불변을 검사합니다.

마지막 페이지에서 실제 파일 대화상자 저장 신호로 내보낸 `station-paging-ui.csv`를 `tests/verify_station_paging_export.py`로 판독합니다. 화면의 1행과 관계없이 전체 1,201행, 정확한 순서/원래 STA·좌표·측점 간격, BOM/21열을 확인합니다. 기존 측점표/구간/평면 구간/횡단 구간/종단 DXF 회귀 검사도 통과했습니다. 화면에서 페이지 제어와 찾은 측점의 행을 확인했습니다.
