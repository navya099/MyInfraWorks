# 평면 DXF 구간 출력 (0.32)

DXF 창의 시작/끝 STA로 필요한 구간만 출력합니다. 최초 기본값은 전체 노선입니다. 전체 범위 버튼은 현재 노선의 정확한 시점/종점을 채웁니다. 창을 다시 열 때 노선 길이가 바뀌었으면 전체 범위로 갱신합니다. 범위 설정은 프로젝트에 저장하지 않습니다.

## 경계와 좌표

범위는 0 ≤ 시작 < 끝 ≤ 노선 길이, 최소 길이 1m입니다. 숫자가 아닌 값·무한대·노선 밖 범위는 거부합니다. 양 끝을 정확히 포함하고, 내부의 네이티브 선형 분할점과 STA 0 기준 정규 간격을 합쳐 정렬합니다. 중심선과 좌우 가장자리는 같은 측점 집합을 사용하며 기존 곡선 선분 근사 방식을 유지합니다.

출력 좌표는 기존 로컬 동/북 또는 DEM EPSG:5179입니다. 구간 시작으로 원점을 옮기지 않습니다. Z는 실제 종단곡선/보정고와 각 가장자리 횡단구배를 반영하며 화면 표시용 띄우기를 제외합니다. 동일 좌표 모드로 구간별 출력한 도면은 같은 좌표계에서 비교할 수 있습니다.

주석을 켜면 구간 양 끝과 원래 STA 0 기준 정규 주석을 출력합니다. 예를 들어 125.25~875.75m, 주석 200m이면 125.25, 200, 400, 600, 800, 875.75입니다. 구간 끝점 1mm 미만의 중복 주석을 합칩니다. 문자에 원래 STA를 사용하며 구간 시작을 0으로 바꾸지 않습니다. 표식/문자의 Z는 중심 계획고입니다. [주석 크기와 회전](dxf-station-labels.md)은 기존과 같습니다.

최대 30,000측점(도로 90,000정점)과 2,000주석 제한은 선택 구간에 적용합니다. 전체가 한도를 넘는 100km 노선도 50,000~50,100m 구간은 1m 간격 101측점으로 출력합니다. DXF의 999 주석에 출력 범위와 원래 STA/좌표 유지 여부를 기록합니다.

## 변경과 검증

범위 및 기존 설정 변경은 결과를 무효화합니다. 비동기 완료와 저장 직전에도 입력 서명을 비교하여 신호 없이 바뀐 입력의 오래된 도면을 거부합니다. 설계/DEM/revision 변경 시에도 기존 무효화가 적용됩니다. 현재 STA 선택·설계 모델·undo 이력·프로젝트 v7·네이티브 DLL v018은 유지합니다.

`verify_dxf_range.gd`와 `--dxf-range-smoke`를 같은 사용자 데이터 경로에서 실행하고, 출력 fixture 폴더를 `tests/verify_dxf_range_export.py`에 전달합니다. ezdxf에서 오류/자동 수정 0건, 소수 구간 양 끝·기존 STA·로컬/투영 좌표·2%/4% 횡단구배·원곡선 접선 경계·실제 포물선 표고·전체 범위 호환을 확인했습니다. 계산 검사는 잘못된 범위, 1m 최소 길이, 30,000측점 한계와 긴 노선 부분 출력을 포함합니다.

UI에서는 실제 저장 대화상자 신호, 범위 복원, 모델/이력 불변, 입력 무효화, 계산 중 변경 및 저장 직전 입력 서명을 검사했습니다. UI 화면과 출력 원곡선/직선 도면을 렌더링하여 확인했고 기존 평면/주석/종단/횡단 DXF 검사도 통과했습니다.
