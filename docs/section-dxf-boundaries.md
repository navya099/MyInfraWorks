# 횡단 DXF 주요 선형 경계 (0.38)

횡단 DXF 창에서 주요 선형 경계 포함을 켜면 출력 구간 안의 설계 경계 측점을 자동으로 포함합니다. 기본은 꺼짐이며 옵션을 명시적으로 끈 결과는 기존과 같은 도면 문자열입니다. 옵션은 창에 유지하지만 프로젝트에는 저장하지 않습니다.

## 경계의 의미

현재 네이티브 선형의 PI 측점, 독립 종단의 PVI 측점, 평면 요소 시작/끝, BVC/EVC를 수집합니다. 평면 요소 경계에는 직선·원곡선·완화곡선 전환점이 포함됩니다. PI는 선형이 제공하는 노선상의 PI 측점이며 원래 PI 교점 좌표 자체에 횡단을 배치하는 기능이 아닙니다. 실제 횡단은 해당 STA에서 선형 접선에 수직으로 표본화합니다.

출력 구간 밖 경계는 제외합니다. 정규 측점·정확한 구간 양 끝·사용자 추가 STA와 정렬하여 0.0000001m 미만으로 가까운 측점을 합칩니다. 우선순위는 구간 양 끝 > 자동 선형 경계 > 사용자 추가 STA > 정규 측점입니다. 옵션을 끄면 기존 추가 STA의 우선순위로 돌아갑니다.

예를 들어 길이 100m, PVI 50m, 종단곡선 길이 20m라면 BVC=40m·PVI=50m·EVC=60m가 포함됩니다. 정규 간격 100m와 추가 STA 12.25m를 사용하면 최종 횡단은 0, 12.25, 40, 50, 60, 100m입니다. PVI 제어점 높이 대신 실제 종단곡선과 현재 설계면의 표고를 사용합니다.

## 수량과 도면

경계 포함 횡단 수는 병합된 최종 횡단 중 자동 경계가 겹친 개수입니다. 양 끝·정규·사용자 추가 STA와 겹친 경계도 포함하므로 옵션을 켰을 때 증가한 횡단 수와 같지 않을 수 있습니다. 전체 500횡단·100,000표본과 한 횡단 20,000표본 제한을 최종 목록에 적용합니다. 초과하면 구간이나 간격을 조절하도록 안내합니다.

[기존 횡단 도면](section-dxf.md)의 H:V=1:1·m 단위·모든 요소 Z=0·레이어·DATUM·원지반/설계면 조회·결측 선 끊기·배치 방식을 유지합니다. 지도/EPSG 좌표 출력은 아닙니다. 켠 도면에는 자동 경계 포함을 나타내는 999 주석을 기록합니다.

옵션 변경 시 산출물과 저장을 무효화합니다. 비동기 완료와 저장 직전 서명에도 옵션을 포함하므로 신호 없이 바뀐 옵션의 오래된 결과도 거부합니다. 설계·undo 이력·프로젝트 v7·DLL v018을 변경하지 않습니다.

## 검증

`verify_section_boundaries.gd`: 실제 BVC/PVI/EVC·PI/원곡선/완화곡선 전환 경계, 구간 안 경계만 포함, 사용자 추가/정규 측점과 병합 우선순위, 기본 끄기 호환, 입력 불변, 경계 추가 후 500횡단/100,000표본 제한.

`--section-boundaries-smoke`: 기본 꺼짐·추가 STA와 동시 사용·실제 저장 신호·설계/이력 불변·옵션 변경 무효화·계산 중 변경·신호 없는 옵션 변경 시 저장 거부.

`tests/verify_section_boundaries_export.py`: 독립 ezdxf 오류/자동 수정 0건, 정확한 원곡선 및 50m 완화곡선 경계·BVC/PVI/EVC·부분 구간·경계/추가 STA 병합, 실제 포물선 계획고와 2%/4% 횡단구배, UI 도면. 기존 추가 STA·횡단 구간·횡단·종단·평면 DXF 회귀 검사도 통과했습니다. 화면에서 경계 옵션과 최종 횡단 목록을 확인했습니다.
