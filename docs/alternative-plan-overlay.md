# 보관 대안 평면 중첩 — 0.24

0.25부터 같은 선택으로 [종단 중첩](alternative-profile-overlay.md)도 함께 표시합니다. 아래는 평면 표시의 동작과 범위입니다.

대안 창에서 보관본을 선택하고 선택 대안을 평면에 중첩 표시를 켭니다. 창을 닫으면 보관 중심선은 보라색, 현재 노선은 주황색으로 함께 보입니다. 범례에는 보관본 이름을 표시합니다. 평면의 중첩 해제 버튼 또는 대안 창의 체크 해제로 지웁니다. 빈 목록/미선택 상태에서는 켤 수 없습니다.

## 형상과 범위

보관본 PI·반경·완화길이·독립 PVI로 별도 KRoadAlignment를 구성하고 네이티브 polyline을 받아 수평 좌표만 보관합니다. 현재 노선의 표시 폴리라인과 같은 방식이며 PI 직선 연결을 사용하는 기능이 아닙니다. 저장된 설계나 현재 모델을 전환하지 않고 원본 DEM·지형 메시도 복제/재계산하지 않습니다.

현재와 참조는 동일한 map_rect와 지형 범위로 변환하므로 확대·이동·측점 맞춤에서도 좌표와 축척이 같습니다. 보라색 선은 겹친 위치도 볼 수 있도록 주황색보다 조금 두껍게 그리며 화면상 선 두께는 도로 폭이나 이격 거리를 뜻하지 않습니다. 보관 선에는 편집 핸들을 만들지 않습니다. PI 선택/추가/삽입/드래그는 기존 현재 노선에만 적용되고 범례/해제 영역은 노선 입력으로 사용하지 않습니다.

한 번에 하나의 보관 대안을 표시합니다. 중심선 위치 비교이며 도로 가장자리·사면 외곽·종단·3D·토공량 중첩은 제공하지 않습니다. 같은 측점 번호가 같은 지점이라는 가정이나 최근접 이격/교차 판정도 없습니다. 종단고·폭·횡단구배만 다른 대안은 평면 중심선이 같을 수 있으므로 이 중첩만으로 두 설계 전체가 같다고 판단하지 않습니다.

## 캐시와 수명

선택한 설계가 달라질 때만 별도 선형과 표시점을 만듭니다. 카메라·확대·이동·현재 노선 수정이나 보관본 이름 변경은 참조 선형을 다시 생성하지 않습니다. 이름 변경은 범례만 갱신하며 다른 보관본 선택은 표시를 바꿉니다. 중첩이 켜진 상태에서 새 보관본을 만들면 대안 창이 그 보관본을 선택하므로 중첩도 새 선택을 따릅니다.

현재 노선을 수정/undo/적용해도 보관 참조는 유지합니다. 선택 대안 삭제로 선택이 해제되거나 새 DEM/프로젝트/데모로 데이터가 초기화되면 중첩도 지웁니다. 같은 DEM의 프로젝트를 열어도 표시 상태를 넘겨받지 않습니다. 표시 실패 시 이전 참조를 지우고 오류를 알립니다.

중첩 조작은 활성 설계·보관 목록·undo/redo·revision·수량 결과·지형 메시를 변경하지 않습니다. 보관 대안의 실제 추가/삭제/이름 변경은 기존 목록 관리 동작을 그대로 따릅니다. 프로젝트 v7·DLL v018은 유지하고 표시 여부·선택 참조·캐시 좌표는 프로젝트에 저장하지 않습니다.
