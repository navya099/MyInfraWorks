# 평면·종단·횡단 뷰 조작

## 평면과 종단 (0.12)

- 휠 위/아래: 커서를 기준으로 확대/축소합니다. 각 뷰 아래 확대·축소 버튼은 뷰 중앙을 기준으로 조절합니다.
- 가운데 버튼 드래그: 화면을 이동합니다. 왼쪽 버튼은 기존 PI/PVI 편집을 유지합니다.
- 전체 맞춤: 평면은 DEM 전체, 종단은 전체 노선 측점과 기본 표고 범위로 복원합니다.
- 종단 Shift+휠: 측점축만 확대/축소합니다. Ctrl+휠: 표고축만 확대/축소합니다. 평면은 양축 비율을 유지합니다.

확대·이동 후 좌표 표시·선택·드래그·추가가 같은 변환을 사용합니다. 종단의 측점 선택과 Shift+클릭 PVI 추가도 보이는 측점에 대응합니다. 화면 밖의 PVI는 선택 대상에서 제외하되 전체 맞춤의 시·종점은 선택할 수 있습니다. 평면 우클릭은 커서 14px 안의 보이는 PI를 선택합니다. PI 삽입 모드에서도 휠과 가운데 이동을 사용할 수 있습니다.

PI/PVI 편집 드래그가 진행 중이면 화면 확대·이동을 적용하지 않습니다. 편집은 버튼을 놓아 확정하거나 기존 Esc 취소로 끝낸 뒤 화면을 이동하세요. 가운데 버튼을 놓거나 창 포커스를 잃으면 이동을 종료합니다.

종단은 보이는 측점 구간에 대해 화면용 표본 241개와 PVI·종단곡선 경계를 표시합니다. 확대 시 전체 노선의 기존 화면 점을 단순히 늘리는 방식이 아닙니다. 원지반의 좁은 지형 변화가 표본 사이에 있으면 표시에서 빠질 수 있으며 상세 종단 조사와 다릅니다. 그래프는 차트 경계에서 잘라 표시하고, 보이는 측점·표고 범위를 축에 표시합니다.

화면 조작은 설계 매개변수, DEM, undo 이력, 토공량·검토 결과를 변경하지 않습니다. 지형 메시 재생성도 요청하지 않습니다. 평면·종단의 뷰 상태는 서로 독립이며 저장하지 않습니다. 새 DEM/프로젝트·데모를 열면 전체 맞춤으로 초기화합니다. 설계 편집 중에는 수동 축척을 유지하므로 새 점이 화면 밖으로 나가면 전체 맞춤으로 찾을 수 있습니다.

## 횡단 (0.15: H:V 1:1 고정)

도로 확대: 폭과 구배에 맞춰 도로·중심/가장자리 높이를 봅니다. 전체 맞춤: 원지반과 계획면의 표고 범위를 자동으로 맞춥니다. 휠은 양축을 같은 비율로 확대하며 Shift/Ctrl도 축을 분리하지 않습니다. 횡단은 점 편집을 하지 않으므로 왼쪽·가운데·오른쪽 드래그 모두 화면 이동에 사용합니다. 더블클릭은 도로 확대입니다. 표고 기준은 선택 측점의 중심 계획고를 따릅니다.

모든 2D 뷰의 화면 조작은 프로젝트 v5나 네이티브 DLL 형식을 바꾸지 않습니다.


## PI 추가 도구 (0.13)

평면의 기본 상태는 선택·이동입니다. 빈 곳 클릭이나 Shift+클릭은 PI를 추가하지 않습니다. 평면 아래 `PI 추가` 버튼을 켠 동안만 클릭으로 노선 끝에 점을 연속 추가합니다. Esc·우클릭·버튼 해제로 종료하며 확정한 점은 유지합니다. 추가 모드에서도 휠 확대와 가운데 이동을 사용할 수 있습니다. 중간 삽입과 추가 도구는 동시에 켜지지 않습니다.


0.14부터 평면·종단의 `측점 맞춤`으로 현재 선택 측점을 가운데 놓을 수 있습니다. [측점 탐색](station-navigation.md)을 참조하세요.


횡단에서는 수평/수직 1m가 화면에서 같은 길이입니다. 공통 m/pixel 배율로 창 크기와 상위 화면 변환까지 보정합니다. 도로 확대/전체 맞춤은 필요한 영역을 포함하면서 창 비율에 맞는 여백을 더합니다. 수동 화면 크기 변경은 중심과 공통 배율을 유지합니다. 작은 횡단구배가 과장되어 보이지 않는 것이 정상입니다. H:V=1:1은 두 축의 동일 비율을 뜻하며 종이 출력 축척이 아닙니다.
