# 보관 대안 토공량 비교 — 0.20

대안 창의 보관 대안 토공량 비교에서 전체 보관본을 순차 계산합니다. 같은 DEM과 정규 측점 간격·조사 반폭·횡단 표본 간격을 공유하고, 각 대안 고유의 평면/종단 경계 측점은 기존 수량 계산처럼 추가합니다. 따라서 총길이와 단면 수는 대안마다 다를 수 있습니다. 첫 보관본이 기준 대안입니다.

계산은 활성 설계를 전환하지 않고 불변 설계 스냅샷과 공유 DEM으로 별도 작업 스레드에서 수행합니다. 각 보관본의 폭·보정고·좌우 구배·성토/절토 사면비를 사용합니다. 기존 [평균단면법](earthwork.md) 계산을 그대로 호출하며 곡선 면적중심·중첩 합집합·토량변화율 보정 등 기존 제한도 같습니다. 공사비나 우열을 자동 판정하지 않습니다.

## 결과 상태

| 상태 | 의미 | 수량·기준 차이 |
|---|---|---|
| complete | 모든 구간 유효 | 전체 수량. 기준도 complete이면 기준 차이 표시 |
| partial | 일부 구간만 유효 | 유효 부분합. 기준 차이 없음 |
| missing | 유효한 구간이 없음 | 수량/차이 빈 셀(표 NA) |
| error | 선형/조사 조건 등 계산 오류 | 수량/차이와 계산되지 않은 비율 빈 셀. 사유 표시 |

유효한 0m³는 숫자0입니다. NoData나 조사 끝 사면 미접속은 제외 단면으로 집계하고 사유에 결측/경계와 미접속 수를 표시합니다. 유효/전체 길이와 비율을 함께 봅니다. 절토−성토는 보정 전 단순 체적 차이이며 반출입·공사비를 의미하지 않습니다. 여러 대안의 수량을 하나의 사업 수량으로 합산하지 않습니다.

## 중단과 유효성

진행 상태는 완료 개수와 현재 계산 중인 이름입니다. 중단 또는 데이터 변경은 스레드 안전 토큰으로 전달합니다. 네이티브 단면 계산 자체를 중간에 끊지 않고 현재 대안이 끝난 뒤 확인하므로 잠시 기다릴 수 있습니다. 중단 시 계산된 일부 행도 전체 비교 결과로 내보내지 않습니다. 창을 닫아도 작업은 계속할 수 있으며 앱 종료 시에는 중단 요청 후 스레드를 정리합니다.

설계·DEM·목록 추가/이름 변경/삭제·조사 설정이 바뀌면 비교 결과를 폐기합니다. 설계 revision과 별도 목록 revision, 설정 세대를 완료 시 다시 확인합니다. 수량 계산은 설계/목록/undo 이력을 바꾸지 않습니다. 비교 행 선택은 설계나 측점을 자동 전환하지 않습니다. 저장된 대안 적용은 기존 대안 창을 사용합니다.

## CSV 25열

```text
name,baseline_name,method,status,length_m,cut_m3,fill_m3,cut_minus_fill_m3,coverage_ratio,covered_length_m,total_length_m,invalid_sections,excluded_intervals,cut_delta_from_first_m3,fill_delta_from_first_m3,station_step_m,half_width_m,lateral_step_m,width_m,offset_m,left_down_pct,right_down_pct,fill_slope_hv,cut_slope_hv,detail
```

UTF-8 BOM이고 기준명과 method=average_end_area를 모든 행에 기록하므로 행을 정렬해도 원래 기준을 확인할 수 있습니다. 수량은 m³, 길이는m, coverage_ratio는0~1입니다. 부분합/미산출/오류의 기준 차이는 빈 셀입니다. error에서 실제 계산하지 못한 필드도 비워0과 구분합니다. detail은 계산 오류 또는 제외 단면 사유입니다. 출력 시에도 유효성을 확인하며 임시 파일을 완성한 뒤 교체합니다.

비교 결과와 조사 설정은 프로젝트에 저장하지 않습니다. 프로젝트 v7·네이티브 DLL v018은 변경하지 않습니다.
