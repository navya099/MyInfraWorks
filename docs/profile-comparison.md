# 현재·보관 대안 측점별 계획고 비교 — 0.26

대안 창에서 보관본을 선택하고 현재·선택 대안 계획고 비교표를 엽니다. 간격을 정한 뒤 산출을 누릅니다. 중첩 표시와 별도로 선택한 보관본을 사용하며 설계를 적용하지 않습니다. 현재 노선이 없거나 보관본을 선택하지 않으면 산출하지 않습니다.

## 기준과 계산

비교 범위는 노선 시작 0부터 두 노선 중 짧은 수평 선형 길이까지입니다. 절대 STA를 사용하고 길이 비율로 대응하지 않습니다. 긴 노선의 나머지 구간은 비교하지 않으며 양쪽 길이와 공통 길이를 화면/CSV에 기록합니다. 시점 오프셋·측점 방정식은 지원하지 않습니다.

두 독립 네이티브 선형에서 같은 STA의 위치·실제 종단곡선 표고·구배를 계산합니다. 계획고에는 각 설계의 계획고 보정을 더합니다. 차이는 현재 계획고−보관 계획고로 고정합니다. 로컬 좌표는 같은 DEM 원점 기준 동/남(m)이고 수평 이격은 두 좌표 차이의 평면 거리입니다. EPSG 좌표를 이 표에 추가하지 않으며 다른 DEM의 보관본을 비교하지 않습니다.

평면 경로가 다르면 같은 STA는 같은 지리적 지점을 뜻하지 않습니다. 수평 이격은 같은 STA 두 점 간 거리이며 최근접 거리나 노선 전체의 최소 이격이 아닙니다. 0 이격이 산출되어도 노선 전체의 일치 판정은 하지 않습니다. 계획고 차이를 수직 토공 깊이·체적이나 공사비로 해석하지 않습니다. DEM·원지반을 조회하지 않으므로 NoData의 영향을 받는 지반/수량 비교도 아닙니다.

정규 측점 간격은 0.1~10,000m입니다. 공통 범위의 양 끝, 양쪽 PI/PVI·평면 요소 경계·BVC/EVC를 함께 넣습니다. 약 10⁻⁶m 이내의 가까운 경계는 태그를 합치며 공통 끝의 정확한 측점을 우선합니다. 경계 포함 최대 20,000측점으로 제한하고 초과 시 간격을 늘리도록 안내합니다. 양쪽 끝 밖을 외삽하지 않습니다.

## 표시와 유효성

별도 스레드에서 불변 설계 스냅샷으로 산출합니다. 화면은 200행씩 이전/다음 페이지를 지원하고 CSV는 전체 측점을 저장합니다. 행 선택은 현재 노선의 해당 STA로 이동하며 현재 설계/보관본/중첩 선택/undo/revision을 바꾸지 않습니다.

현재 설계·DEM·간격·보관본 선택·이름 변경·목록 추가/삭제가 발생하면 결과를 비우고 저장을 막습니다. 완료 시 설계/목록 revision·선택 인덱스·설정 세대를 확인하므로 A→B→A처럼 선택이 되돌아와도 이전 작업 결과를 사용하지 않습니다. 이전 작업이 끝나기 전에 산출을 다시 누르면 종료 후 재시도 안내를 표시합니다. 창을 닫아도 계산은 계속될 수 있고 앱 종료 시 작업 스레드를 정리합니다.

프로젝트 v7·DLL v018을 유지합니다. 표·산출 간격·페이지와 결과는 프로젝트에 저장하지 않습니다. 수량 계산/중첩 표시의 기존 결과는 비교표 조작만으로 바뀌지 않습니다.

## CSV 20열

```text
saved_name,comparison_basis,station_step_m,current_length_m,saved_length_m,common_length_m,current_offset_m,saved_offset_m,station_m,current_elevation_m,saved_elevation_m,current_minus_saved_m,current_local_east_m,current_local_south_m,saved_local_east_m,saved_local_south_m,horizontal_separation_m,current_grade_pct,saved_grade_pct,events
```

UTF-8 BOM, comparison_basis=same_absolute_station입니다. 길이/좌표/표고는 m, 구배는 %입니다. 보관 이름·간격·각 길이/보정고를 모든 행에 반복하여 CSV 정렬 후에도 조건을 확인할 수 있습니다. Δ와 이격의 실제 0은 숫자 0입니다. events는 regular/start/common_end와 current_/saved_ 접두의 PI/PVI/geometry_boundary/BVC/EVC 태그를 |로 합칩니다. 출력은 임시 파일 완성 후 교체하고 현재 유효한 결과만 저장합니다.
