# 일정 길이 구간별 토공량 — 0.23

토공량 계산 후 일정 길이 구간 집계를 엽니다. 시작·끝 STA(m)와 분할 길이를 입력하고 범위 집계 또는 Enter를 누릅니다. 전체 구간 버튼은 입력한 분할 길이를 유지하며 조사 양 끝으로 범위를 복원합니다. 기본 분할 길이는 1,000m입니다.

## 분할과 계산

입력한 시작 a부터 분할합니다. 예를 들어 250~2,780m를 1,000m로 나누면 250~1,250m, 1,250~2,250m, 2,250~2,780m의 세 구간입니다. 전 노선의 STA 1,000m 배수에 맞추는 기능은 아닙니다. 마지막에는 요청 끝을 그대로 사용하고 짧은 잔여 구간을 버리지 않습니다. 부동소수점 반올림 때문에 생기는 max(10⁻⁹m, |끝 STA|×10⁻¹⁴) 이내의 불필요한 끝 구간은 합칩니다.

분할 길이는 1~1,000,000m이고 결과는 최대 1,000구간입니다. 잘못된 숫자·비유한 값·역순·원본 범위 밖 입력·구간 수 초과는 거절합니다. 원본 수량의 유효성을 한 번 확인한 뒤 측점 배열을 앞에서부터 따라가며 각 분할 범위에 필요한 부분만 전달합니다. DEM을 다시 조사하거나 전체 노선을 매 구간마다 반복 검색하지 않습니다.

각 경계는 [0.22 범위 집계](earthwork-ranges.md)의 단면적 선형 보간과 부분 평균단면법을 사용합니다. 분할된 체적·유효 길이를 합하면 요청 범위 전체와 일치합니다(부동소수점 오차 제외). 원본 단면 간격보다 촘촘하게 분할하더라도 DEM 조사 정밀도가 높아지는 것은 아닙니다. 토량변화율·운반·배분·지질·비용 보정과 교량/터널 분류는 포함하지 않습니다.

## 상태·건수·상세

각 분할 구간은 complete(범위 전부 유효), partial(유효 부분합), missing(유효 구간 없음)입니다. missing의 절토·성토·차이는 NA/빈 셀이고 실제 유효 수량 0은 숫자 0입니다. 유효 비율은 해당 분할 길이에 대한 비율입니다. 상단 합계와 상태는 전체 요청 범위 기준이며 일부 결측이 있으면 유효 부분합으로 표시합니다.

included_source_intervals/excluded_source_intervals는 해당 분할 구간과 양의 길이로 겹친 원본 조사 구간 건수입니다. 한 원본 구간이 두 분할 구간에 걸치면 두 행에서 각각 셉니다. 따라서 행별 건수 합은 원본 구간의 고유 개수가 아니며, 체적/길이 합과 다릅니다. 상세 창에서 각 원본 구간의 경계와 nodata/unclosed 사유를 확인할 수 있습니다.

행을 선택하면 분할 구간 중간 측점으로 이동합니다. 더블클릭하면 기존 범위 상세 창을 같은 시작·끝으로 엽니다. 표시 측점 이동은 설계·undo·revision을 바꾸지 않고 원본 수량도 유지합니다. 표는 200행씩 표시하고 CSV는 현재 페이지와 관계없이 모든 분할 구간을 저장합니다.

시작/끝/분할 길이 입력 변경은 일괄 결과만 지웁니다. 설계·DEM·원본 조사 조건 변경/재계산은 원본과 파생 창 결과를 함께 무효화합니다. 저장할 때 revision과 세 입력값 일치를 다시 확인합니다. 프로젝트 v7·DLL v018은 그대로이며 입력이나 결과는 프로젝트에 저장하지 않습니다.

## CSV 20열

```text
method,boundary_method,station_step_m,half_width_m,lateral_step_m,requested_start_m,requested_end_m,block_length_m,block_index,start_m,end_m,length_m,status,cut_m3,fill_m3,cut_minus_fill_m3,covered_length_m,coverage_ratio,included_source_intervals,excluded_source_intervals
```

UTF-8 BOM, method=average_end_area, boundary_method=linear_section_area입니다. m/m³ 단위이며 coverage_ratio는 0~1입니다. 요청 범위와 분할 설정을 모든 행에 기록합니다. block_index는 입력 시작부터 1 기반 번호입니다. 각 행은 개별 분할 구간의 수량으로 누계가 아닙니다. partial은 알려진 유효 부분합, missing은 세 수량을 빈 셀로 기록합니다. 임시 파일을 완성한 뒤 교체하며 무효화된 결과는 저장하지 않습니다.
