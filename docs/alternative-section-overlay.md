# 보관 대안 횡단 설계면 중첩 — 0.27

대안 창에서 보관본을 선택하고 선택 대안 평면·종단·횡단 중첩을 켭니다. 세 뷰는 같은 보관본을 사용합니다. 횡단에서 주황색은 현재 설계면, 보라색은 보관 설계면, 녹색은 원지반입니다. 어느 뷰의 중첩 해제 버튼이나 대안 창의 체크 해제로 함께 지웁니다.

## 현재 횡단선에 고정된 비교

현재 노선의 선택 STA에서 얻은 중심 좌표와 법선 방향을 사용합니다. 각 횡단 오프셋 d의 실제 좌표에서 원본 DEM, 현재 설계면, 보관 설계면을 평가합니다. 보관 설계면은 보관 노선 전체의 준비된 공간 검색으로 평가하므로 보관 노선의 같은 STA를 가져와 중심을 강제로 맞추지 않습니다. x축 0과 좌/우 방향, 표시 STA는 현재 노선 기준입니다. 다른 경로가 현재 횡단선의 왼쪽을 통과하면 보라색 도로도 그 위치에 나타납니다.

보관본의 실제 네이티브 표시 중심선과 도로 폭·계획고 보정·좌우 횡단구배·절토/성토 사면비를 사용합니다. 평가식과 최근접 선분 선택은 기존 [단순 절성토 미리보기](cut-fill-slopes.md)와 같습니다. 보관 노선의 영향이 없거나 투영 대상 선분이 없는 곳은 원지반을 유지합니다. 보라색과 녹색의 일치는 해당 표본에서 변형이 없다는 뜻이며 보관 노선이 없다는 판정은 아닙니다. 노선 교차·중첩에서는 기존 최근접 선분 방식의 제한이 동일합니다.

원본 DEM 범위 밖/NoData는 유효하지 않은 표본으로 취급하고 선을 끊습니다. 보관 표시는 현재 표본과 별도로 유효성을 검사하며 결측 사이를 연결하지 않습니다. 새 지형 메시를 생성하거나 실제 DEM을 수정하지 않습니다.

## 축척과 화면 범위

기존 횡단의 물리적 H:V=1:1을 그대로 사용합니다. 부모/창 배율을 고려한 같은 m/물리 픽셀로 양축을 표시하고 휠·드래그·크기 변경 후에도 유지합니다. 선 두께는 화면 표시용이고 물리적 도로 폭을 뜻하지 않습니다.

전체 맞춤은 현재 횡단의 초기 조사 폭(반폭 max(100m, 현재 폭×4))과 1:1 맞춤으로 확장된 표시 범위를 사용하고 표본에 포함된 양쪽 설계면 높이를 고려합니다. 보관 노선 전체가 들어오도록 자동으로 탐색하는 기능은 아닙니다. 보관 도로가 멀면 축소/이동으로 조사 범위를 옮깁니다. 도로 확대와 더블클릭은 현재 도로를 기준으로 하므로 떨어진 보관 도로는 화면 밖일 수 있습니다.

화면용 횡단 표본 사이를 선분으로 연결합니다. 보관 도로 가장자리의 정확한 교차점 추출이나 절성토 면적/체적 차이 계산을 하지 않으며 표시 간격보다 좁은 형상은 확대해서 확인해야 합니다. 같은 STA의 두 단면을 개별 중심 기준으로 비교하거나 수량 차이를 자동 추정하는 기능도 아닙니다. 3D 지형은 현재 설계만 반영합니다.

## 캐시와 수명

보관본 선택 시 이미 생성한 참조 중심선으로 별도 KRoadCore 공간 검색을 한 번 준비합니다. 원본 DEM을 공유하고 표본 평가 시 원지반과 보관 설계면을 조회합니다. 카메라/측점/확대/이동·현재 설계 수정·이름 변경 때 보관 선형이나 공간 검색을 다시 만들지 않습니다. 전체 맞춤에 필요한 표본은 표시 시 계산합니다.

현재 노선이 없으면 횡단 기준 위치/법선을 정할 수 없어 횡단은 그리지 않습니다. 보관 캐시는 유지하며 현재 노선 복원 시 다시 표시할 수 있습니다. 선택 삭제·새 DEM/프로젝트/데모·중첩 해제는 세 뷰의 참조를 함께 비웁니다. 중첩 조작은 설계·보관본·undo/revision·기존 수량 결과·현재 지형 메시를 바꾸지 않습니다.

프로젝트 v7·DLL v018을 유지하고 표시 여부·표본·공간 검색 캐시는 프로젝트에 저장하지 않습니다.
