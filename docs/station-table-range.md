# 측점표 구간 산출과 CSV (0.34)

상단 측점표에서 시작/끝 STA를 지정하고 산출합니다. 최초 기본값은 전체 노선이고 전체 범위로 현재 노선 양 끝을 복원합니다. 창을 다시 열 때 노선 길이가 바뀌면 전체 범위를 갱신합니다. 범위 설정은 프로젝트에 저장하지 않습니다.

## 측점과 이벤트

노선 안에서 길이 1m 이상의 범위를 지정합니다. 잘못된 숫자·무한대·범위 밖·역전·너무 짧은 범위를 거부합니다. 기존 측점 간격 0.1~10,000m를 사용하고 STA 0 기준 정규 측점, 정확한 구간 양 끝, 내부 PI/PVI·평면 요소 경계·BVC/EVC를 합칩니다. 구간 밖 이벤트는 제외합니다. 0.000001m 미만으로 가까운 이벤트는 태그를 합치며 정확한 구간 양 끝을 우선합니다.

중간 구간 양 끝은 range_start/range_end, 노선의 실제 시종점은 start/end로 표시합니다. 화면에서는 구간 시작/구간 끝/시점/종점으로 구별합니다. 구간 시작을 STA 0으로 재설정하지 않습니다. 행을 선택하면 원래 STA로 이동하며 설계나 undo 이력을 바꾸지 않습니다.

경계 포함 최대 20,000행 제한을 선택 구간에 적용합니다. 예를 들어 100km 노선을 1m 간격으로 전체 산출하면 거부하지만 50,000~50,100m 구간은 101행입니다.

## CSV와 상태

[기존 측점표](alignment-station-table.md)의 21열 UTF-8 BOM CSV를 유지하며 산출된 모든 행을 저장합니다. 실제 종단곡선의 계획고·구배, 보정고와 좌우 횡단구배를 사용합니다. 로컬 X는 동쪽, Y는 남쪽이고 원점 정보가 있는 경우 투영 동/북 좌표도 기록합니다. 원점이 없으면 투영 좌표를 빈 셀로 남깁니다. 직선 반경·지반 결측·결측 차이도 기존 빈 셀 처리를 유지합니다. events에는 새 구간 경계 태그가 추가될 수 있습니다.

입력/설계/DEM 변경은 결과를 무효화합니다. 비동기 완료·행 선택·저장 직전 입력 서명을 검사하여 신호 없이 바뀐 입력의 오래된 결과를 사용하지 않습니다. 현재 STA 이동은 산출물을 유지합니다. 전용 창을 상속하여 추가했으며 기존 DXF 창의 입력에는 구간 측점표 UI를 추가하지 않습니다. 프로젝트 v7·DLL v018을 유지합니다.

## 검증

`verify_station_range.gd`와 `--station-range-smoke`를 같은 사용자 데이터 경로에서 실행하고 출력 fixture 폴더를 `tests/verify_station_range_export.py`에 전달합니다.

계산 검사는 소수 구간 양 끝·이벤트 우선순위/태그 병합·PI/PVI/평면 경계/BVC/EVC·실제 포물선·횡단구배·전체 범위 동일 행·NoData·잘못된 범위·1m 최소 구간·20,000행 한계·긴 노선 부분 산출을 포함합니다. 독립 Python 검사는 실제 UI에서 저장한 BOM/21열 CSV의 원래 STA·좌표·태그·빈 셀과, 별도 산식에 의한 포물선 계획고·구배·가장자리 표고를 확인합니다.

UI 검사는 실제 저장 대화상자 신호, 원래 STA 행 이동, 설계/이력 불변, 범위 복원, 입력 무효화 및 오래된 계산/저장 거부를 포함합니다. 기존 측점표와 평면 구간/횡단 구간/종단 DXF 회귀 검사도 통과했습니다. 화면에서 구간 입력과 산출 행을 확인했습니다.
