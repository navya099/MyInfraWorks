# 측점표 주요 경계 필터 (0.36)

측점표 산출 후 주요 경계만 보기를 체크합니다. 기본은 꺼짐이며 전체 산출 행을 표시합니다. 켜면 다음 events 태그 중 하나 이상이 있는 행을 표시합니다.

| 태그 | 의미 |
|---|---|
| start / end | 노선 실제 시종점 |
| range_start / range_end | 지정 구간 양 끝 |
| PI / PVI | 평면/종단 제어점 측점 |
| geometry_boundary | 평면 요소 경계 |
| vertical_curve_start / vertical_curve_end | 종단곡선 시작/끝 |

regular만 있는 행은 숨깁니다. regular와 경계 태그가 병합된 행은 유지합니다. 원본 행과 순서·계획고·좌표·결측 정보를 수정하지 않고 별도의 표시 목록을 구성합니다. 필터 전환은 재계산하지 않으며 첫 페이지로 돌아가지만 현재 STA와 설계/undo 이력은 유지합니다.

## 탐색과 저장

200행 페이지와 행 선택은 표시 목록을 기준으로 합니다. STA 찾기는 산출 구간 안의 요청값에서 가장 가까운 표시 행으로 이동하며, 동률이면 작은 STA를 선택합니다. 예를 들어 표시 행이 0과 1,200m뿐이면 600m 요청은 0m, 601m 요청은 1,200m로 이동합니다. 필터를 끄면 기존 전체 행 기준 탐색으로 돌아갑니다. 검색으로 새 행을 계산하거나 보간하지 않습니다.

페이지 안내에 표시 행 수와 CSV 전체 행 수를 구분합니다. CSV는 필터와 현재 페이지에 관계없이 전체 산출 행을 기존 UTF-8 BOM/21열로 저장합니다. 주요 경계만 저장하는 기능은 포함하지 않습니다. 필터 선택은 창에 유지하며 프로젝트에 저장하지 않습니다.

입력/설계/DEM 변경은 원본 결과와 표시 목록을 함께 무효화합니다. 페이지/검색/행 선택 시에도 기존 revision/입력 서명 검사를 적용합니다. 설계 계산·프로젝트 v7·DLL v018은 유지합니다.

## 검증

`verify_station_events.gd`: 모든 경계 태그와 regular 병합, 실제 포물선의 BVC/PVI/EVC 목록, 잘린 구간 양 끝, 완화곡선/PI의 내부 경계 및 원본 행 보존.

`--station-events-smoke`: 기본 전체 표시·주요 경계 필터·재계산/generation 불변·설계/이력 불변·필터 기준 행 선택/STA 동률 탐색·2페이지 표시 목록의 인덱스·필터 해제 복원·오래된 결과 초기화·재산출 후 필터 유지·실제 CSV 저장 신호. 다중 페이지 매핑 검사는 경계와 정규 행이 번갈아 있는 합성 목록을 사용합니다.

`tests/verify_station_events_export.py`: 실제 노선 1,201행에서 경계 2행만 표시한 상태의 CSV를 독립 판독하여 전체 1,201행·정규 측점·원래 STA/좌표·순서·BOM/21열 보존을 확인합니다. 기존 측점표/페이지/구간/평면·횡단·종단 DXF 회귀 검사도 통과했습니다. UI 화면에서 주요 경계 체크와 표시 행 수를 확인했습니다.
