# 측점 탐색 — 0.14

횡단 뷰 위의 STA(m) 입력, 이동(m) 간격과 이전/다음 버튼으로 노선을 탐색합니다. 측점은 노선 시작을 0으로 하는 수평 선형 호장이며 시점 오프셋/측점 방정식을 적용하지 않습니다. 입력 표시·증분은 0.001m이고 이는 입력 해상도이며 DEM·노선의 물리적 정확도와는 다릅니다. 이동 간격 기본값은 20m입니다. 범위를 벗어나면 0 또는 노선 끝으로 제한하며 노선이 없을 때는 입력과 이동을 막습니다.

슬라이더·종단의 빈 곳 클릭·토공량/설계 검토표의 측점 선택과 동일한 선택 상태를 사용합니다. 평면의 하늘색 표식은 선택 측점과 횡단 방향이며 넓은 화면에서도 보이도록 방향선에 최소 픽셀 길이를 둡니다. 실제 도로 폭의 축척 표시는 아닙니다. 종단의 세로 선택선, 횡단 단면과 3D의 하늘색 도로 횡단/중심 표식을 함께 갱신합니다. 화면 밖 표식은 해당 뷰를 맞추어 확인합니다.

## 측점 맞춤

평면·종단 아래 측점 맞춤은 선택 위치를 해당 뷰 중앙으로 이동합니다. 평면과 수동 종단의 현재 축척을 유지합니다. 전체 범위 종단에서 처음 맞추면 노선 길이의 약 20% 범위로 확대합니다. 전체 맞춤은 기존 전체 화면 복원입니다. 3D 측점 보기는 기존처럼 가까운 도로 중심으로 카메라를 이동합니다. 측점 탐색 자체는 카메라를 움직이지 않습니다.

## 정보

- 계획고: 정확한 선형 sample(s)의 종단고 + 계획고 보정입니다. 도로 중심고이며 좌·우 가장자리는 횡단구배를 적용합니다.
- 지반고: 계산용 DEM에서 선택한 중심 위치를 쌍선형 보간합니다. 결측은 NoData입니다.
- 계획−지반: 중심 한 점의 높이 차이입니다. 양수는 계획이 높고 음수는 낮습니다. 단면적이나 토공량이 아닙니다.
- 구배: 동일 sample(s)의 종단구배 × 100입니다. 오르막은 양수입니다.
- 반경: 현재 평면 곡률의 절댓값 역수입니다. 완화곡선에서는 측점마다 달라지고, 곡률이 1e−12 미만이면 직선으로 표시합니다.
- 좌표: 정보줄 툴팁에 로컬 동 X/남 Y를 표시합니다. 원점 정보가 있는 DEM에서는 EPSG:5179 E/N을 표시합니다.

3D 표식은 화면 표시용으로 도로면보다 0.65m 들어 그립니다. 원지반이 유효하면 중심 원지반과 연결선도 표시합니다. 이 표시 오프셋은 설계·지형·수량에 포함하지 않습니다. 원지반이 결측이어도 계획선형 위치는 표시합니다.

## 상태와 검증

측점 변경은 조회·뷰 상태이며 설계 매개변수와 undo/revision을 바꾸거나 비동기 지형 작업을 요청하지 않습니다. 수량/설계 검토 결과도 유지합니다. 도로를 편집하면 기존과 같이 선택된 노선 길이 비율을 유지하여 새 노선의 대응 위치를 표시합니다. 노선 삭제 시 표식을 지우고 undo로 복원하면 다시 표시합니다. 선택 측점과 이동 간격은 프로젝트 v5에 저장하지 않습니다.
