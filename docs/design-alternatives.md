# 설계 대안 — 0.19

대안 창에서 현재 설계에 이름을 붙여 보관하고 다시 적용합니다. 보관본은 설계 매개변수의 불변 스냅샷입니다. 이후 현재 노선을 바꾸어도 자동 갱신하지 않습니다. 다른 이름으로 새 검토안을 보관하세요. 동일 이름을 덮어쓰는 기능은 제공하지 않습니다.

## 내용과 동작

PI 좌표, R/Ls, 독립 PVI 측점·제어고·Lv, 도로 폭·보정고, 좌우 구배와 절토/성토 사면비를 저장합니다. 원본 DEM·미리보기 높이·텍스처·중심선 메시·카메라·선택 측점·undo 이력·수량/검토/DXF 결과는 저장하지 않습니다. 같은 DEM을 공유하므로 지형 데이터를 보관본마다 복제하지 않습니다.

목록에는 평면 선형 호장과 PI/PVI 수를 표시합니다. 현재 설계 매개변수와 같은 보관본은 현재와 같음으로 표시하고 적용 버튼을 막습니다. 대안 길이 차이는 공사비나 설계 적합성 판정이 아닙니다. 수량 비교는 각 대안을 적용한 후 토공량 계산을 사용합니다.

보관과 이름 변경은 현재 설계와 revision, 설계 undo 이력을 바꾸지 않습니다. 적용은 현재 편집/추가 모드를 종료하고 검증된 보관본을 기존 changed 경로로 적용합니다. 한 번의 적용은 undo 한 단계이고 이전 형상으로 되돌릴 수 있습니다. 이미 같은 설계를 적용하면 revision이나 이력을 늘리지 않습니다. 대안 목록 자체의 보관·이름 변경·삭제는 설계 undo에 포함하지 않습니다.

삭제는 확인 창을 거치며 해당 보관본만 제거합니다. 현재 설계는 유지합니다. 확인 중 목록/데이터가 갱신되면 대기 중 삭제를 취소합니다. 최대20개, 이름은 줄바꿈/탭 없이 1~60자이며 앞뒤 공백을 제거한 이름의 중복을 거절합니다.

## 프로젝트 v7

프로젝트 저장은 현재 활성 설계와 alternatives 배열을 함께 저장합니다. 각 항목은 name과 design만 가지며 길이·점 수는 로드 시 검증/재계산합니다. design은 packed PI/PVI 배열과 숫자 설정으로 구성됩니다. 프로젝트의 DEM은 계속 최상위 terrain/source 한 쌍으로 공유합니다. 바이너리 컨테이너 KROAD2 헤더를 유지하고 v1~v6는 빈 목록으로 읽습니다. 0.18 이하 앱은 v7을 열 수 없습니다.

로드할 때 현재 설계와 모든 대안의 이름/수, 배열 형식·개수·유한값, 지형 범위, 폭/구배/사면비, 평면·종단곡선 조건을 확인합니다. 하나라도 잘못되면 현재 프로젝트와 기존 목록을 교체하지 않습니다. 새 DEM/데모는 이전 지형의 목록을 비우고, 다른 프로젝트는 그 프로젝트의 목록으로 교체합니다.

보관/이름 변경/삭제 후 프로젝트 저장을 눌러야 파일에 반영됩니다. 대안 창에도 같은 프로젝트 저장 버튼을 제공합니다. 파일 작업 중에는 완료 후 저장하도록 안내합니다. 별도 자동 저장은 이번 기능에 포함하지 않습니다.

## 검사

verify_alternatives.gd는 불변 스냅샷, DEM 없는 직렬화, 유일 이름·20개 제한, 좌표·프로필·숫자 거절을 검사합니다. --alternatives-smoke는 실제 보관/적용, 한 단계 undo/redo, 현재와 동일한 적용의 불변성, 삭제 확인, 빈 노선 복원, v7 파일 roundtrip, 손상 목록의 원자적 거절, v6 호환과 DEM 교체를 검사합니다.
