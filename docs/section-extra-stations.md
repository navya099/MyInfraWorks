# 횡단 DXF 추가 STA (0.37)

DXF → 횡단 DXF 창의 추가 STA(m)에 쉼표로 구분한 절대 STA를 입력합니다. 예: `123.45, 567.89`. 현재 STA 추가는 현재 횡단 위치의 STA를 목록 끝에 넣습니다. 비우기는 추가 목록만 지웁니다. 최초 기본값은 빈 목록이며 입력은 프로젝트에 저장하지 않습니다.

## 입력과 병합

최대 100개 입력을 허용합니다. 중복 입력도 개수 제한에는 포함합니다. 쉼표 앞뒤 공백과 과학적 표기 숫자는 허용하지만 빈 항목·빈 토큰을 만드는 연속/끝 쉼표·잘못된 숫자·무한대·NaN·출력 구간 밖 STA는 거부합니다. 전체가 빈 문자열/공백이면 추가 측점이 없는 것으로 처리합니다. 세미콜론이나 공백만으로 값을 구분하지 않습니다.

[구간 출력](section-dxf-range.md)의 양 끝과 STA 0 기준 정규 횡단에 추가 STA를 합쳐 오름차순으로 배치합니다. 0.0000001m 미만으로 가까운 측점은 병합하며 정확한 구간 양 끝 > 사용자 추가 STA > 정규 측점 순으로 우선합니다. 동순위 추가값끼리는 정렬상 앞 값을 유지합니다. 정규 25m와 추가 25.00000001m는 추가값을, 구간 시점 0m와 추가 0.00000001m는 정확한 시점을 보존합니다. 화면 라벨은 기존 소수 셋째 자리이므로 계산 측점의 더 작은 차이는 라벨에서 보이지 않을 수 있습니다.

현재 STA 추가는 현재 값이 출력 구간 안인지 확인합니다. 전체 범위 버튼은 출력 구간만 복원하고 추가 목록은 유지합니다. 노선/출력 구간을 변경해 추가 STA가 범위 밖이 되면 산출을 거부하므로 목록을 수정하거나 비웁니다.

## 도면과 상태

추가 후 합계에 최대 500횡단·전체 100,000표본 제한을 적용합니다. 한 횡단의 최대 20,000표본도 유지합니다. 추가 입력 개수와 중복 병합 후 총 횡단 수를 표시합니다.

기존 원지반·설계·축·문자 레이어, H:V=1:1, m 단위와 Z=0 횡단 배치, DATUM·결측 선 끊기를 유지합니다. 지도/EPSG 좌표가 아닙니다. DXF의 999 주석에 입력 추가 STA를 각각 기록합니다. [기존 횡단 도면](section-dxf.md)과 같은 실제 지표/설계면을 조회합니다.

추가 입력의 변경·현재 STA 추가·비우기는 이전 산출물을 무효화합니다. 비동기 완료/저장 직전 입력 서명에도 추가 문자열을 포함합니다. 단순 현재 STA 이동은 산출물을 유지합니다. 설계와 undo 이력·프로젝트 v7·DLL v018은 변경하지 않습니다.

`verify_section_extra.gd`: 정렬·정규/구간 양 끝과 중복 병합·우선순위·빈 입력 완전 호환·부분 구간·잘못된 토큰/유한성/범위·100개 제한·추가 후 500횡단/100,000표본 예산.

`--section-extra-smoke`: 빈 기본값·현재 STA 삽입·정규/추가 중복·실제 저장 신호·설계/이력 불변·범위 밖 현재 STA 거부·잘못된 추가 입력·입력 무효화·오래된 계산/저장 거부.

`tests/verify_section_extra_export.py`: ezdxf 오류/자동 수정 0건, 정확한 추가 측점과 정렬/중복/구간·라벨·실제 1:1 횡단의 중심/좌우 가장자리 2%/4% 횡단구배·UI로 추가한 현재 측점. 기존 횡단/구간/종단/평면 DXF와 측점표 경계 필터 회귀 검사도 통과했습니다. UI에서 입력란과 산출 목록을 확인했습니다.
