# 횡단 DXF 구간 출력 (0.33)

DXF → 횡단 DXF 창에서 시작/끝 STA를 지정합니다. 처음은 전체 노선이고 전체 범위 버튼으로 현재 노선 양 끝을 복원합니다. 창을 다시 열 때 노선 길이가 바뀌었으면 전체 범위를 갱신합니다. 범위 설정은 프로젝트에 저장하지 않습니다.

## 표본과 도면

범위는 0 ≤ 시작 < 끝 ≤ 노선 길이, 최소 길이 1m입니다. 숫자가 아닌 값·무한대·역전·범위 밖 입력을 거부합니다. 구간 양 끝과 STA 0 기준 정규 횡단을 합칩니다. 예를 들어 125.25~975.75m에 간격 400m면 125.25, 400, 800, 975.75m입니다. 구간 시작을 STA 0으로 재설정하지 않습니다. 경계에서 0.0000001m 미만으로 가까운 정규 횡단은 정확한 경계로 대체합니다.

최대 500횡단과 전체 100,000표본 제한은 선택한 구간에 적용합니다. 각 횡단의 최대 20,000표본 제한은 그대로입니다. 전체 100km 노선이 1m 간격 한도를 넘더라도 50,000~50,010m 구간은 11횡단으로 출력할 수 있습니다.

[기존 횡단 DXF](section-dxf.md)의 H:V=1:1과 지표/계획면 계산을 유지합니다. 원지반·설계·축·문자 레이어를 나누며 결측에서 선을 끊고 단독 유효 표본은 POINT로 남깁니다. 모든 요소 Z=0, 단위 m인 횡단 배치 도면입니다. 지도/EPSG 좌표가 아닙니다. DATUM과 배치 원점에 따라 표고를 복원하며 지정 열 수로 다시 배치합니다. 999 주석에 출력 STA 범위를 기록합니다.

## 상태와 검증

입력 변경과 설계/DEM revision 변경은 산출물과 저장을 무효화합니다. 비동기 완료와 저장 직전 입력 서명을 비교하므로 프로그램에 의한 신호 없는 입력 변경도 오래된 산출물을 내보내지 못합니다. 현재 STA 이동은 결과를 유지합니다. 설계·undo 이력·프로젝트 v7·DLL v018은 변경하지 않습니다.

`verify_section_dxf_range.gd`와 `--section-dxf-range-smoke`를 같은 사용자 데이터 경로에서 실행하고 출력 fixture 폴더를 `tests/verify_section_dxf_range_export.py`에 전달합니다.

계산 검사: 소수 STA 경계·원래 정규 간격·입력 보존·전체 범위 호환·경계 근접 중복 제거·결측/전체 결측·잘못된 범위·1m 최소 구간·500횡단 경계·전체 표본 제한·100km 노선 부분 출력.

독립 ezdxf 검사: 오류/자동 수정 0건, 정확한 STA·레이어·모든 요소 Z=0·횡단 1:1의 2%/4% 횡단구배·DATUM/배치·결측에서 선 끊기·전체 범위 형상 보존. UI 검사는 실제 저장 신호·모델/이력 불변·현재 STA 독립·범위 복원·무효화·계산 중 변경·저장 직전 서명을 포함합니다. 기존 횡단/종단/평면 구간/측점 주석 DXF 회귀 검사도 통과했습니다.
