# 종단 DXF 출력 — 0.30

DXF 창에서 종단 DXF...를 열고 STA 범위·간격·세로 확대 배율을 지정해 산출 후 저장합니다. 처음에는 전체 노선·20m·10배입니다. 전체 범위 버튼은 정확한 노선 양 끝을 사용합니다. 같은 노선 길이에서 창을 다시 열면 지정 범위를 유지하고 길이가 바뀌면 전체 범위로 맞춥니다.

## 도면 좌표와 배율

```text
X = STA - 시작 STA
Y = (실제 표고 - DATUM) × 세로 배율
Z = 0
실제 표고 = Y / 세로 배율 + DATUM
```

X 1 도면 단위는 1m이고 Y는 표고 차이에 지정 배율을 곱한 값입니다. CAD 가져오기 단위는 m로 지정하며, 세로를 10배로 출력한 도면에서 수직 길이를 실제 높이로 읽으려면 10으로 나눕니다. 배율 1은 양축이 같고 1~100배를 지원합니다. 이 설정은 화면의 횡단 1:1이나 설계 자체를 바꾸지 않습니다.

DATUM은 선택 구간의 유효 원지반/계획고 표본 최솟값 아래 10m 단위 기준표고입니다. 각 축 눈금에는 실제 STA와 복원된 절대 표고를 표기합니다. 범위·DATUM·계획고 보정·간격·배율·원지반 결측 수와 좌표 식도 ASCII 영문 TEXT로 기록합니다. 입력 표고의 수직 기준을 변환하지 않습니다.

모델 공간에 하나의 종단 도면을 배치하며 지도/EPSG 좌표나 3D 지형 위치가 아닙니다. 긴 노선은 CAD에서 확대하거나 STA 범위를 줄여 출력할 수 있습니다. 도면은 R12 열린 3D POLYLINE/32 플래그 VERTEX를 사용하고 모든 Z를 0으로 기록합니다. 단독 유효 원지반 표본은 POINT입니다. 기존 [횡단 DXF](section-dxf.md)와 같은 엔티티 작성·저장 방식을 재사용합니다.

| 레이어 | 내용 | 색상 |
|---|---|---|
| KROAD_PROF_GROUND | 현재 노선 원지반 | 초록 |
| KROAD_PROF_DESIGN | 실제 종단 계획고+보정 | 노랑 |
| KROAD_PROF_AXIS | 축 | 회색 |
| KROAD_PROF_TEXT | 범위·배율·기준표고·눈금 | 흰색 |

## 표본과 결측

원본 DEM을 정확한 네이티브 수평 선형 위치에서 조회하고 실제 종단곡선 표고를 더해 계획선을 만듭니다. 계획선은 PVI 제어점 연결선이 아니며 3D 화면의 표시용 0.5m도 포함하지 않습니다.

지정 시작부터 정규 간격 표본을 만들고 정확한 시작/끝, 범위 안의 PVI/BVC/EVC, 종단곡선 내부의 구배 0 정점과 평면 요소 경계를 합칩니다. 약 10⁻⁶m 이내 가까운 표본은 병합하고 지정 양 끝을 우선합니다. 실제 곡선은 표본 사이 선분으로 근사하므로 더 자세한 형상은 간격을 줄여 출력합니다. DEM 정확도나 물리적 조사 해상도는 간격/출력 자릿수를 줄인다고 높아지지 않습니다.

원지반 결측/범위 밖에서 원지반선만 끊습니다. 계획선은 노선의 설계 표고이므로 원지반 없이도 유지합니다. 전 구간 원지반 결측이면 원지반 도형은 없지만 계획선·축·문자와 결측 수는 남습니다. 유효 0 표고를 결측으로 사용하지 않습니다. 지반과 계획고의 차이에 대한 면적·체적·공사비를 산정하지 않습니다.

## 조건·유효성·검사

측점 간격은 1~10,000m, 범위는 현재 노선 안에서 시작보다 끝이 크고 길이 1m 이상이어야 합니다. 잘못된 숫자·비유한 값·역순·범위 밖은 거절합니다. 경계 포함 최대 20,000표본이며 초과하면 간격을 늘리거나 범위를 줄이도록 안내합니다. 지정 구간 밖을 외삽하지 않습니다.

불변 스냅샷으로 별도 스레드에서 산출합니다. 설계/DEM/간격/범위/배율 변경은 결과를 비우고 완료 시 revision·조건 세대·입력 서명을 확인합니다. 저장 시에도 현재 입력과 일치하는지 확인합니다. 현재 STA 이동은 선택 범위를 바꾸지 않으므로 결과를 유지합니다. 창을 닫아도 계산은 계속될 수 있고 종료 시 스레드를 정리합니다.

설계·undo·원본 DEM·메시와 프로젝트 v7·DLL v018은 유지합니다. 입력 범위/간격/배율/결과는 프로젝트에 저장하지 않습니다. 임시 파일 완성 후 교체합니다.

Godot 검사가 포물선·비대칭 정점·1배/10배·원지반 결측/전부 결측·음수 표고 DXF를 user://에 만들고 PROFILE DXF FIXTURES 경로를 출력합니다. UI 검사 후 독립 tests/verify_profile_dxf_export.py에 그 경로를 전달합니다. ezdxf 1.3.0에서 오류·자동 수정 0건과 좌표/표고/배율·결측 처리를 확인하고 도면도 렌더링했습니다. AutoCAD에서 직접 실행한 검증은 아닙니다. Python/ezdxf는 검사에만 사용하며 Godot 내보내기의 실행 의존성이 아닙니다.
